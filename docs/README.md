## 合併前的版本差異（歷史對照）

以下保留合併前的快照比較；目前 `master` 已包含右欄的功能；後續另將候選字級／列高調整為 20px／30px，詳見更新紀錄。

| 項目 | 合併前主線（59cf6ec） | 原功能分支（9b73ae7，已納入主線） |
| --- | --- | --- |
| 候選字級／列高 | 24px／38px | 相同 |
| 候選布局 | 單欄，每頁最多 9 項 | 預設單欄，向右展開為最多 4 欄、36 項；實際欄數依候選數量調整 |
| 候選方向鍵 | ↑／↓、←／→ 逐項移動，邊界換頁 | 展開後 ↑／↓ 在欄內循環，←／→ 切欄；數字鍵選目前欄 |
| 窗框與組字底線 | 請求 Windows 11 圓角；一般組字為虛線 | 請求直角；一般組字為實線，目標選字為粗實線 |
| 繁簡提示 | Ctrl+Shift+F；沒有常駐標籤 | 保留原快捷鍵，增加右 Ctrl＋右 Shift＋T／S 及短暫模式提示 |
| 聲調提早輸入 | 無音節完成後補入聲韻的規則 | 對無詞庫匹配且未手動鎖定的前一音節，嘗試補入晚到的聲韻；有效音節保持分字 |
| 語境評分 | 詞頻與詞長加成 | 額外加入少量固定字詞搭配加減分，並非訓練式 bigram 模型 |
| 標點 | Ctrl 組合鍵 | 增加 Shift 標點、反引號前導鍵及 Ctrl+Shift+; 冒號 |
| 錯誤提示音 | 呼叫系統提示音 | 預設靜音；不代表按鍵都被接受 |
| 安裝 | COM／TSF 註冊與使用者覆寫 | 另嘗試加入既有繁體中文語言項目的 InputMethodTips；失敗時顯示警告 |
| 核心測試模組 | 13 項 | 15 項；兩個分支均有 5 組 CTest |

目前請取得 `master` 進行測試。切換已有 checkout 的分支前，先處理自己的未提交修改；切換之後重新建置並指定正確 DLL 安裝，不能只切 Git 分支便假設宿主已換版本。

## 如何解讀測試紀錄

- 日期命名的報告描述當時版本，保留原本的測試數量、畫面與限制。
- [2026-10-24 發布準備](RELEASE_READINESS_2026-10-24.md) 記錄 0.4.0 主線準備，不涵蓋後來的四欄選字與提早聲調修正。
- 現行操作以本索引、操作指南及程式碼為準；舊報告中的虛線、圓角與 13 項測試不應套用到目前主線。

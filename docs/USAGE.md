# 操作指南

適用：主線 `master`，功能基準 `9b73ae7`。合併前差異見 [歷史分支對照](README.md)。使用標準大千注音排列；下列符號鍵以一般美式實體鍵位描述。

## 組字與提交

初始為中文、繁體輸出。輸入 `su3cl3` 可組出「你好」，按 Enter 才送入宿主。組字中可混入英文、數字小鍵盤字元及標點，並在游標處編輯。

| 情境 | 按鍵與行為 |
| --- | --- |
| 注音輸入 | 一聲為 Space；二、三、四、輕聲分別為 6、3、4、7；1、2 是聲母鍵，不是聲調鍵 |
| 組字中移動 | ←／→ 移動組字游標；Home／End 移到首尾 |
| 修改內容 | Backspace 倒退刪除；Delete 刪除游標後內容 |
| 展開候選 | 組字中按 ↓，以游標位置開啟候選 |
| 選字 | 按數字 1–9，或以方向鍵定位後按 Enter；只鎖定選擇，仍保留組字 |
| 確認整句 | 候選窗關閉後再按 Enter |
| 取消 | 候選窗中 Esc 回到組字；組字中 Esc 清除組字 |
| 空白 | 有未完成注音時為一聲；已有組字且無待結音注音時插入空格，不用來選字 |
| 中英切換 | 單按 Shift；與其他按鍵組合使用時不作單按切換 |

選錯字可再按 ↓ 重新開啟候選。手動選過的區段會鎖定，其餘未鎖定區段可隨後續輸入重算。錯誤按鍵預設沒有蜂鳴聲，但重複聲母、介音或韻母等不合規輸入仍可能被攔截。

## 多欄候選

1. 按 ↓ 先開啟單欄候選，每頁最多 9 項。
2. 候選總數多於 9 項時，按 → 展開並移向下一欄；展開容量為每頁 36 項，畫面依實際候選數顯示 1–4 欄，每欄最多 9 項。
3. 展開後 ↑／↓ 在目前欄內循環；←／→ 切到相鄰欄。欄位不足或頁面邊界時會依可用候選調整位置。
4. PgUp／PgDn 切換上一頁／下一頁並回到頁內第一項；展開後到達右側邊界也可能換頁。
5. 數字 1–9 指的是**目前所在欄的列號**，不是整頁的第 1–9 項。
6. 在第一頁的第一欄按 ← 可收合。候選選定後也會結束展開，回到可繼續編輯的組字狀態。

候選字高設定為 20px、列高 30px，窗框為無陰影的直角細框；序號 1–9 只顯示在左側共用欄，候選欄不重複序號或分隔線，選取項使用整格藍底。只有多頁時在底部狀態列顯示頁碼；沒有常駐繁簡標籤。這些是原始碼尺寸，並非已提供 DPI 自適應或可在設定介面調整的選項。

## 繁簡切換

| 按鍵 | 效果 |
| --- | --- |
| Ctrl+Shift+F | 在繁體、簡體之間切換 |
| 右 Ctrl＋右 Shift＋T | 指定繁體 |
| 右 Ctrl＋右 Shift＋S | 指定簡體 |

指定模式的快捷鍵需使用鍵盤**右側的兩顆修飾鍵**。切換時會在滑鼠游標上方顯示小型白底提示「✓ 已切換到 繁體中文」或「✓ 已切換到 簡體中文」，約 1.2 秒後消失，不搶輸入焦點。提示使用獨立視窗，不會覆蓋候選內容或在計時結束時隱藏候選窗。轉換使用 OpenCC 衍生的單字元映射；不等同完整的詞組語境轉換。

## 全形標點

中文模式下，標點會進入組字區並保留底線。可移到標點位置按 ↓ 改選替代符號。

| 輸出 | Ctrl 組合 | 目前版本其他輸入方式 |
| --- | --- | --- |
| ， | Ctrl+, | Shift+,；先按反引號再按逗號 |
| 。 | Ctrl+. | Shift+.；先按反引號再按句號 |
| ？ | Ctrl+/ | Shift+/；先按反引號再按 / |
| ； | Ctrl+; | — |
| ： | Ctrl+Shift+; | Shift+; |
| ！ | Ctrl+Shift+1 | — |
| 、 | Ctrl+' 或 Ctrl+反斜線 | 以逗號候選改選 |
| 「／」 | Ctrl+[／Ctrl+] | 直接按 [／]；這是單邊符號輸入，沒有自動補另一半 |

反引號是實體鍵盤常見的 `` ` `` 鍵；先按它再按可對應的標點鍵即可輸入全形符號，連按兩次則輸入反引號本身。不同鍵盤配置或遠端輸入的 OEM 鍵映射需要實機確認。

## 快速打字容錯的範圍

- **聲韻亂序**：音節尚未結束時，可以先按韻母再按聲母，由槽位重排。例如 `k`＋`2` 顯示 ㄉㄜ，接 `7` 得到「的」。
- **聲調提早**：例如 `2`＋`4`＋`l`（ㄉ＋ˋ＋ㄠ），會嘗試補成 ㄉㄠˋ，候選可能為「到」或「倒」。前一音節須未手動鎖定，且原組合沒有精確詞庫匹配、補入後有匹配。
- **保留有效音節**：`h4ji3` 應維持「次我」，不能把後字的 ㄨ 吸收成「促」。是否算有效由當前詞庫判斷。
- **修正聲調**：游標前有未鎖定的已結音音節、且目前沒有待輸入聲韻時，6／3／4／7 可更新前一音節的聲調；Space 仍依空白規則處理。
- **字詞搭配**：解碼器對部分「的／得」、「在／再」等搭配加減分。規則有限，可能選錯；需要時用候選明確選字。

## 自訂詞與學習

`data/custom_words.txt` 每行以 Tab 分隔「詞彙、空白分隔的注音、詞頻」。例如：

```text
範例詞彙<Tab>ㄈㄢˋ ㄌㄧˋ ㄘˊ ㄏㄨㄟˋ<Tab>500000
```

請把 `<Tab>` 換成真正的 Tab，修改後關閉並重新開啟使用 E-IME 的程式，讓新實例重載詞庫。此檔已受 Git 追蹤，私人詞彙請勿隨文件修改一起提交。

選字學習另存於 `data/sync/device_<hostname>_<writer-id>.delta`，不經 Git 傳送。雲端傳輸由外部服務負責；不要更名或複製日誌成另一份 `.delta`，以免當成另一個來源重算。更多安裝與故障處理見 [換機指南](SECOND_DEVICE_TEST.md)。
